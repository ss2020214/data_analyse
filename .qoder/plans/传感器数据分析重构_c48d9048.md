## Task 2: 修正时间对齐逻辑 (peaks.py)

**目标**：对齐准则从"hit rate"改为"每个窗口检出峰数与标注峰数之差最小"。

修改 `analysis/peaks.py` 中的 `estimate_lag()` 函数：

**新的对齐目标函数**：
```python
# 对每个 lag，计算每个标注窗口内检出峰数与标注 count 的差异
# score(lag) = -sum(|peaks_in_window_i - label_count_i|) for all windows
# 选择 score 最高（差异最小）的 lag
```

逻辑：
1. 遍历 lag 范围 [-10, +10]s
2. 对每个 lag，将标注窗口平移后，计算每个窗口内的峰数
3. 对比每个窗口的峰数与标注的 count 值
4. 选择使所有窗口 |检出峰数 - 标注数| 之和最小的 lag
5. 若多个 lag 同分，取 |lag| 最小者

## Task 5: 更新绘图和统计模块以支持4组 (plot.py, main.py, summary*.py)

**目标**：所有图表和统计支持4组对比（normal, pathological, infection, sham）。

**重要约束**：
- 不绘制组平均值线，只展示个体轨迹
- **归一化处理消除个体差异**：由于不同兔子传感器基础阻值、个体差异等因素，绝对值不可直接比较，需对结果进行归一化

### 5.1 归一化策略

对特征输出进行以下归一化（消除个体初始状态差异，只看变化趋势）：

| 归一化方式 | 适用场景 | 公式 |
|-----------|---------|------|
| W1基准差值 | 各兔子W1统一为0，看相对变化 | `v'(w) = v(w) - v(w1)` |
| W1基准比值 | 各兔子W1统一为1，看倍率变化 | `v'(w) = v(w) / v(w1)` |
| 基线归一化 | 消除传感器量纲差异 | `amp_norm = 峰幅 / 当前基线` |
| z-score | 消除个体量级，只保留时间形状 | `z(w) = (v(w) - 个体均值) / 个体std` |

**应用规则**：
- 峰值类特征（amp_mean等）：使用「基线归一化」，输出 amp/baseline 无量纲比值
- 跨周趋势图：使用「W1基准差值」或「W1基准比值」，统一起点
- 组间对比图：使用「z-score」，消除量级差异后对比形状
- Per-peak 箱线图：使用「除以该兔子W1中位数」，消除传感器量纲差异
